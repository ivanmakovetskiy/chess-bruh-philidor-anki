# Contributing

Improvements to annotations, source matching, accessibility and build reliability are welcome.

## Report a card issue

Please include:
- Original Chess.com game URL.
- Move number and side to move.
- The displayed answer or explanation.
- Your suggested correction and supporting analysis.

Remember: a different engine move is not automatically an error. Include your engine version and search settings when comparing recommendations.

## Propose a change

1. Describe the issue before making a large change.
2. Keep generated decks and board images out of commits.
3. Do not add video footage, audio or copied commentary without permission.
4. Validate that reconstructed moves are legal and card counts remain explainable.

This repository has no chosen code license yet. Discuss licensing with the repository owner before submitting substantial code contributions.
